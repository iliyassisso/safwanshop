# متجر SafwanShop

هذه ملفات الموقع الجاهزة للنشر على GitHub Pages. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub، ثم من Settings > Pages اختر النشر من الفرع الرئيسي والجذر.

تبدأ الصفحة من `index.html`. صفحات المنتجات والطلب والتأكيد موجودة بجانبها. يتضمن الموقع قسم «منتجات إلكترونية» الجديد.

ملاحظة: صور بعض المنتجات وخطوط الموقع تُحمّل من الإنترنت.
